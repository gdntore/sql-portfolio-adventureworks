# SQL & Data Validation — AdventureWorks 2017

## Sobre o projeto

Projeto desenvolvido para praticar SQL Server utilizando o banco de dados
AdventureWorks 2017, com foco em consultas, análise e validação de dados.

O projeto faz parte do meu portfólio de QA e demonstra como utilizo SQL
para consultar informações, validar dados e investigar possíveis
inconsistências em um banco de dados.

## Objetivo

Aprimorar meus conhecimentos em SQL e aplicar consultas em cenários
relacionados à rotina de Quality Assurance, desenvolvendo uma base para
validação e análise de dados durante os testes de software.

## Tecnologias

- SQL Server
- SQL Server Management Studio (SSMS)
- AdventureWorks 2017

## Conteúdos praticados

### Consultas básicas
- SELECT
- DISTINCT
- WHERE

- LIKE

### Funções e agregações
- COUNT
- SUM
- AVG
- GROUP BY
- HAVING
- ORDER BY

### Relacionamentos
- INNER JOIN
- Utilização de aliases
- Relacionamento entre tabelas
